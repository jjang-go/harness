# Run Checks

다음을 순서대로 실행하고 결과를 간결히 요약한다. 실패가 있으면 어떤 명령이 왜 실패했는지 먼저 보고한다.

1. 린트: `{{LINT}}`
2. 테스트: `{{TEST}}`

각 명령의 성공/실패와 핵심 출력만 보고하고, 실패 시 수정 방향을 제안한다.
