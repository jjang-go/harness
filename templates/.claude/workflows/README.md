# workflows/ — 동적 워크플로우 (복사용 아님)

`.claude/workflows/*.js` 는 여러 서브에이전트를 조율하는 동적 워크플로우 스크립트다.
**손으로 작성하는 게 아니라**, 세션에서 `/workflows` 로 실행한 결과를 `s` 키로 저장하면 이 폴더에 `.js` 파일로 생성된다. 각 파일은 `/<이름>` 커맨드가 된다.

- 직접 복사할 스타터가 없다. 필요할 때 `/workflows` 로 만들어 저장하라.
- 프로젝트 워크플로우는 같은 이름의 개인용(`~/.claude/workflows/`)보다 우선한다.
- 커밋 대상이다(팀과 공유). 이 README 는 안내용이며 지워도 된다.
