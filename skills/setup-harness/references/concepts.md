# 초보자 용어집 (concepts)

사용자가 "이게 뭐예요?", "rules가 뭐죠?", "권한이랑 훅 차이가 뭐예요?"처럼 개념을 물을 때 읽고, **쉬운 말로** 풀어 설명한다. 그대로 읽어주지 말고, 상황과 사용자의 프로젝트에 맞춰 한두 문장으로 답한다.

## 목차
1. `.claude/`가 뭔가요
2. 프로젝트 스코프 vs 글로벌 스코프

---

## 1. `.claude/`가 뭔가요

프로젝트 폴더 안의 `.claude/` 폴더는 **Claude Code가 이 프로젝트에서 어떻게 일할지** 알려주는 설정이 모인 곳이다. 여기 둔 파일은 보통 git에 커밋해서 팀원과 공유한다. 대부분의 사람은 `CLAUDE.md`와 `settings.json` 두 개만으로 충분하다.

## 2. 프로젝트 스코프 vs 글로벌 스코프

- **프로젝트 스코프** = 지금 이 저장소 안(`./CLAUDE.md`, `./.claude/`). 이 프로젝트에만 적용되고 팀과 공유된다. **이 위저드는 항상 여기에만 만든다.**
- **글로벌 스코프** = 내 컴퓨터의 `~/.claude/`. 내 모든 프로젝트에 적용되는 개인 설정. 위저드는 여기를 건드리지 않는다.
- 둘 다 있으면 보통 프로젝트 설정이 우선한다.

## 3. CLAUDE.md

Claude가 **매 세션 시작 때마다 읽는 프로젝트 안내서.** "빌드는 이 명령으로, 스택은 이거고, 이런 규칙을 지켜줘" 같은 걸 적어둔다. 적어두면 매번 설명할 필요가 없다. 너무 길면(200줄 넘으면) 일부를 `rules/`로 나누는 게 좋다. `/memory` 명령으로 열어 편집한다.

## 4. rules (규칙 파일)

`.claude/rules/` 안의 주제별 규칙 파일. CLAUDE.md가 길어질 때 주제별로 쪼개 두는 용도다. 특별한 점: 파일 맨 위에 `paths:`를 적으면 **그 경로의 파일을 열 때만** 규칙이 로드된다. 예를 들어 테스트 규칙은 테스트 파일을 만질 때만 켜져서, 평소 컨텍스트를 아끼게 해준다.

## 5. settings.json — 권한(permissions)

`Claude가 어떤 명령/도구를 써도 되는지`를 정하는 규칙. CLAUDE.md가 "권유"라면 권한은 **강제**된다.
- `allow`: 확인 없이 바로 실행해도 되는 것 (예: `npm test`)
- `deny`: 절대 못 하게 막는 것 (예: `rm -rf`)
자주 쓰는 안전한 명령을 `allow`에 넣으면 매번 "실행할까요?" 묻는 걸 줄일 수 있다.

## 6. settings.json — 훅(hooks)

특정 순간(예: 파일 편집 직후)에 **자동으로 실행되는 작은 동작.** 예를 들어 "파일을 저장할 때마다 포매터를 돌려라" 같은 걸 자동화한다. 권한과 마찬가지로 Claude가 따르든 말든 시스템이 강제 실행한다. 잘못 걸면 매 편집마다 실패할 수 있으니, 위저드는 실제로 포매터가 있을 때만 제안한다.

## 7. skills (스킬)

`/이름`으로 부르는 재사용 가능한 작업. `.claude/skills/<이름>/SKILL.md` 폴더로 만든다. 사람이 직접 부를 수도 있고, Claude가 상황에 맞으면 알아서 쓸 수도 있다. 지금 쓰고 있는 이 위저드(`/setup-harness`)도 스킬의 한 종류다.

## 8. agents (서브에이전트)

자기만의 별도 작업 공간(컨텍스트)에서 도는 보조 일꾼. 메인 대화를 깔끔하게 유지하면서 검토·조사 같은 일을 따로 맡길 때 쓴다. 예: 읽기 전용 `code-reviewer`. `@`를 입력해 직접 부를 수도 있다. 초보자에게는 처음부터 필요하진 않다 — "확장" 깊이에서 맛보기로만 제공한다.

## 9. 무엇을 어디에 넣어야 하나요

| 하고 싶은 것 | 넣을 곳 |
|--------------|---------|
| 프로젝트 맥락·규칙을 Claude에게 알려주기 | `CLAUDE.md` |
| 특정 명령 허용/차단, 자동 동작 | `.claude/settings.json` (권한·훅) |
| 주제별·파일별로 규칙 나누기 | `.claude/rules/*.md` |
| `/이름`으로 부르는 작업 추가 | `.claude/skills/<이름>/SKILL.md` |
| 별도 컨텍스트의 전문 보조 | `.claude/agents/*.md` |

> 초보자에게는 "일단 CLAUDE.md + 권한부터, 필요해지면 늘리면 된다"가 가장 안전한 출발점이다.
